## 🌌 The Vision

This isn't just a portfolio — it is an **Engineering Dashboard**, a **Cinematic Journey**, and a **Tactile Interface**. Designed not just to list projects, but to ***prove*** technical ability through relentless attention to detail, sub-ms performance optimization, and hardware-accelerated fluid physics.

Every pixel is intentional. Every animation serves a purpose. Every interaction tells a story.

| Principle | Implementation |
|-----------|---------------|
| **Cinematic First** | Newspaper editorial layouts, scroll-triggered reveals, and theater-lighting transitions |
| **Performance Obsessed** | IntersectionObserver-based viewport culling, GPU-accelerated transforms, debounced scroll listeners |
| **AI-Native** | Embedded xAI Grok assistant with contextual awareness of every project, skill, and experience |
| **Mobile Re-Engineered** | Not responsive — *re-architected*. Haptic feedback, fluid pill clouds, strict viewport firewalls |
| **3D Interactive** | Spline-powered mechanical keyboard with per-keycap click detection and React event bridging |

## ⚡ Performance Engineering

### Rendering Optimizations

| Technique | Implementation | Impact |
|-----------|---------------|--------|
| **Viewport Culling** | `IntersectionObserver` on all WebGL/Canvas instances (Cobe globe, Spline 3D) pauses render loops when off-screen | 0% GPU idle load |
| **Hardware Acceleration** | `translateZ(0)` + `will-change: transform` via `.smooth-gpu` utility class on heavy repaint nodes | Browser compositor thread VRAM control |
| **Render Loop Clamping** | GSAP tickers heavily clamped; ScrollTrigger velocity uses mathematical smoothing to prevent infinite layout recalculations | Eliminates wheel-input jank |
| **Debounced ScrollTrigger** | `requestAnimationFrame` throttles scroll events — drops unnecessary sub-frame executions | 60-120fps smooth scrolling |
| **Progressive Media Loading** | High-res elements load progressively behind framer-motion opacity tweens | Seamless visual queue |
| **Tree Shaking** | Vite build process guarantees minification specifically against `@splinetool` and `gsap` dependencies | Optimal JS chunk payload |
| **Spline Mobile Scaling** | Custom Spline canvas dynamically adjusts spatial XYZ scaling to 15% for mobile footprints | Escapes 60% viewport clamping on 1024px screens |

### Performance Budget

| Metric | Target | Achieved |
|--------|--------|----------|
| **Frame Rate** | 60fps | 60-120fps |
| **GPU Idle Load** | < 5% | 0% (viewport culling) |
| **Scroll Jank** | None | None (Lenis + debounced rAF) |
| **Layout Thrashing** | Zero | Zero (velocity smoothing) |
| **Mobile Viewport** | No fragmentation | Strict `overflow-x: clip` |

## 🚀 Setup & Local Ignition

### Prerequisites

| Requirement | Version |
|-------------|---------|
| **Node.js** | 18.x or higher |
| **npm** | 9.x or higher |
| **Git** | 2.x or higher |

### Quick Start

**1. Clone the Matrix**
```bash
git clone https://github.com/theRkakkad/Rk-Portfolio.git
cd Rk-Portfolio
```

**2. Install Neural Dependencies**
```bash
npm install
```

**3. Configure the Environment**
```bash
cp .env.example .env
```

Edit `.env` and add your API keys:
```env
VITE_XAI_API_KEY=your_xai_grok_api_key_here
```

> **Get your xAI API Key:** Visit [console.x.ai](https://console.x.ai/) to generate an API key for the Grok model.

**4. Launch the Engine**
```bash
npm run dev
```

The reactor goes live at **`http://localhost:3000`**

## 🌍 Deployment

### Vercel (Recommended)

This project is optimized for Vercel deployment with zero configuration.

**Option 1: Vercel CLI**
```bash
npm i -g vercel
vercel
```

**Option 2: Git Push**
1. Push your code to GitHub
2. Import your repository at [vercel.com/new](https://vercel.com/new)
3. Add environment variables in Vercel dashboard
4. Deploy automatically on every push

**Option 3: One-Click Deploy**
[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/theRkakkad/Rk-Portfolio)
