--- [00] EXECUTIVE OVERVIEW ---------------------------------------------------------------------
This portfolio is not a website; it is an interactive 3D application engineered for extreme 
visual fidelity and performance. It utilizes a custom-built animation pipeline that binds
mathematical physics (repulsion, magnetism, and inertia) with cinematic art direction.

--- [01] THE ARCHITECTURAL STACK ---------------------------------------------------------------
* ENGINE: React 19 / Vite (Parallel Module Execution)
* MOTION PHYSICS:
  - GSAP v3.14 (GreenSock Animation Platform) - High-performance timeline manipulation.
  - Framer Motion v12 - Declarative spring-based physics and layout shifting.
  - Lenis (Studio Freight) - Weight-based global smooth scrolling for inertia.
* 3D VISUALIZATION:
  - Spline Runtime - Real-time 3D interactive mesh rendering (Skills Keyboard).
  - Cobe - Lightweight WebGL-based planetary canvas (Dynamic Globe).
  - Three.js / @react-three/fiber - Supporting 3D scaffolding.
* INTELLIGENCE:
  - Gemini AI (Google GenAI) - Built-in AI Portfolio Cognition for real-time assistant responses.
* STYLING:
  - Tailwind CSS v4 - Modular, utility-driven layout architecture.
  - Custom Layer Filters: Noise textures, Glass-morphism, and Backdrop Blurs.

--- [02] VISUAL IDENTITY & COLOR THEORY --------------------------------------------------------

--- [03] SECTOR BREAKDOWN: THE NARRATIVE ARC ----------------------------------------------------

1. THE HERO (THE SYNOPSIS)
   - [MECHANIC: MAGNETIC INERTIA] - The "View my work" buttons utilize GSAP's speed-interpolation.
     The buttons don't just follow the mouse; they resist it with simulated weight.
   - [MECHANIC: DYNAMIC MARQUEE] - The background text reacts to scroll velocity.
     Directional Vector: Scrolls Right when deltaY < 0; Scrolls Left when deltaY > 0.
   - [THE GOD-EFFECT RESUME]: A 1.5s delay sequence that simulates document generation with a 
     high-frequency shimmer mask on the button border.

2. THE ABOUT (THE MICRO-FILM)
   - [MECHANIC: 500vh PINNING] - The section pins the user to a fixed coordinate.
   - [IDE SIMULATION]: A React state-controlled IDE (rachit_profile.ts). As the user scrolls, 
     the state triggers a "Theme Update" which re-renders the code snippet, highlighting 
     different developer facets (Engineer, Dev, AI, Minimalist).
   - [THE HUMAN MASK]: A cursor-reveal logic where the AI-stylized image (Mask A) is layered
     above the real photo (Mask B). Moving the mouse creates a 150px radius reveal hole,
     metaphorically showing the "human soul" within the code.

3. THE SKILLS (THE 3D WORKSHOP)
   - [THE SPLINE BRIDGE]: A custom lazy-loaded Spline scene. Interaction is handled by 
     emitting cross-window events.
   - [MECHANICAL HAPTICS]: Each keycap in 3D (Spline mesh) is mapped to a React Audio context.
     Selecting a key triggers a 0.35 volume mechanical click and a physical Y-axis depression.
   - [TERMINAL LOGIC]: A custom "Typewriter" hook handles the side panel description.
     It features a [CURSOR_BLINK] state and [BUFFERED_TEXT] character rendering.

4. THE EXPERIENCE (THE PHYSICAL ARCHIVE)
   - [STACKING STACK]: Using Framer Motion's `useScroll` and `useTransform`.
   - Physics: Each "Experience Card" is assigned a z-index and an opacity ramp.
   - Logic: As the page moves, the current card's Y-position translates [-40px * i] while its
     Scale shrinks to [0.96^i]. This creates a "Paper piling" effect that feels tactile.

5. THE PROJECTS (THE MAGNETIC FIELD)
   - [REPULSIVE PHYSICS]: The project cards are not just floating. They use a distance-vector 
     formula: `force = Math.pow((maxDistance - distance) / maxDistance, 2)`.
   - If the cursor enters the project's gravity field, the card "pushes away" (magnetic repulsion),
     making the project grid feel like a living, organic organism.
   - [THE CASE-STUDY FLIP]: Clicking a project triggers an "Expansion Fluctuation."
     The card's bounding box is calculated in real-time, and the image component is 
     interpolated from the card's specific coordinates to `(0,0,100vw,100vh)` globally.

6. CERTIFICATES (THE VERIFIED LEDGER)
   - [CATEGORY ENGINE]: A state-driven filtering system between "Hackathons" and "Skills."
   - [STAMP OF AUTHENTICITY]: When a certificate enters the viewport, a Red "VERIFIED" 
     stamp drops with a scale animation (1.5x to 1.0x) to simulate a physical ink strike.

7. THE CONTACT (THE VOID)
   - [THE DARKENING GRADIENT]: A scroll-bound transform that lerps the body background from
     #F6F3EE to #0a0a0a, creating a "Theater lights dimming" effect.
   - [THE GET IN TOUCH EXPLOSION]: Clicking the CTA button triggers a scale mutation of 50x.
     The blue circle expands until it becomes the background, revealing the contact form.
   - [THE FORM ARCHITECTURE]: A 6-stage sequential form with real-time field validation and 
     animated underline status indicators.

--- [04] MICRO-INTERACTIONS & USER EXPERIENCE --------------------------------------------------
* CUSTOM CURSOR: A dual-circle system (Cursor + Follower) with Mix-Blend-Difference.
  - Hovering on interactions: Inner circle disappears; outer circle expands 2.5x with backdrop-blur.
* SOUNDSCAPE: Optional, sensory haptic clicks for 3D interactions.
* PERFORMANCE:
  - Images: Lazy-loaded with custom placeholders.
  - 3D: Suspense-wrapped with a spinning loader fallback.
  - Scrolling: Optimized at 60-120fps using requestAnimationFrame (Lenis).
